# Personal Portfolio Website

A personal portfolio website developed using Python, FastAPI, Jinja2, SQLite, HTML, and CSS. This project showcases my professional profile, technical skills, projects, and contact information through a clean, responsive, and modern design.

The website includes sections for Home, About, Skills, Projects, and Contact. It features light and dark theme switching with cookie-based preference storage, a contact form with validation, and SQLite database integration to store submitted messages. CSS animations and responsive styling provide a smooth user experience across different screen sizes.

**Technologies Used:** Python, FastAPI, Jinja2, SQLite, HTML5, CSS3, and Uvicorn.

**Installation and Setup:** Clone the repository, navigate to the project directory, create and activate a Python virtual environment, and install the dependencies using `pip install -r requirements.txt`. Start the application using `uvicorn main:app --reload` and open `http://127.0.0.1:8000` in your browser.

This project helped me gain practical experience in backend development with FastAPI, template rendering with Jinja2, SQLite database integration, form handling, cookie management, responsive web design, and GitHub version control.
